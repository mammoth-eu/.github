# MAMMOth
Welcome to the developer portal of MAMMOth! This is an EU project that aims to create ready-to-use solutions multi-attribute, multimodal bias mitigation in AI systems.
Find here material that you can use for the development of fairer systems. 
For more information about the project visit [mammoth-ai.eu](https://mammoth-ai.eu/). 

## 📒 [AI Fairness Definition Guide](https://github.com/mammoth-eu/FairnessDefinitionGuide)

## 🔬 [MAI-Bias desktop for local data](https://github.com/mammoth-eu/mammoth-commons) 
## 🦣 [Solution catalogue](https://mammoth-eu.github.io/mammoth-commons/)


## What to do?

- Learn about defining fair AI while respecting stakeholder feedback in our fairness definition guide.
- Install the MAI-Bias toolkit in your organization and consult with it about bias analysis and mitigation in created AI models. This is ideal for resource intensive workflows and shared data. Install a more lightweight desktop application to work on local data.
- Take a look at our catalogue of solutions. We welcome submission of new ones.
